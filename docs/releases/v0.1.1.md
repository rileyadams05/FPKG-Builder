## FPKG Builder 0.1.1

This release provides Linux x86-64 installers for Linux Mint, Ubuntu, Debian, Fedora, and compatible distributions. Download the `.deb` for Debian-based systems or the `.rpm` for Fedora-based systems. `SHA256SUMS` contains checksums for the release downloads.

### Requirements

- A PS4 jailbreak that works with your console and supports your Linux setup.
- Linux installed and configured on the PS4.
- Itemzflow installed on the PS4 and used to dump the game.
- Enough available storage for the resulting package.

Initial PS4 jailbreak and Linux setup ordinarily uses a computer; a Raspberry Pi setup method is another option. FPKG Builder is for use after Linux and Itemzflow are already running on the PS4.

### Prepare and build

1. Let Itemzflow finish dumping the base game and, if desired, its matching game update.
2. Put the base-game folder and its matching `<TITLE_ID>-patch` folder inside one parent folder named `Itemzflow`. Leave any GP4 project files in place with their game folders. Logs and `.complete` marker files are optional; FPKG Builder ignores them and leaves them unchanged.
3. Connect or mount the storage in Linux. Use the Linux mount path; an Orbis path such as `/mnt/usb0` is not automatically available under Linux.
4. Open FPKG Builder and drop the complete `Itemzflow` folder onto the application's drop area. Processing starts automatically. The application reuses suitable GP4s or prepares missing project data in memory, combines the base game and matching update into one package, displays measured progress, and validates the result.
5. Once validation succeeds, choose the location for the resulting `.pkg` file. FPKG Builder does not install the package on the PS4; use your existing local package-installation method.

The source dump and GP4 files are left in place. DLC is outside the scope of this application and is not processed.

### Verification

The release build runs controlled GP4 reuse/generation, base-plus-update, package validation, and source-preservation checks. GitHub Actions installs and launches the `.deb` on Ubuntu and the `.rpm` on Fedora. This release has not been tested on PS4 hardware with a real Itemzflow dump; package validation does not prove that an fPKG will install or run on the console.
